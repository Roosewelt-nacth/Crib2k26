# Crib 2k26: parish Christmas crib archive

Layouts, references, blueprints, prompts and build packs for the parish crib, from 2023 to 2026 and onward.

- **Showcase site:** open `index.html` (or enable GitHub Pages on the `main` branch, root folder).
- **Working memory for Claude:** `CLAUDE.md`. Open it in any new chat or account to continue the project.
- **2026 build pack:** `2026/pack/index.html` and `2026/docs/build-pack.pdf`.

| Folder | Contents |
|---|---|
| `2023/` | The 2023 layout drawing (add the final photo and sketches here) |
| `2026/images/` | Blueprint, block-out views, church key plan, concept render |
| `2026/docs/` | Build pack PDF, ideas, final theme, image prompts, component prompts |
| `2026/pack/` | Interactive build pack: parts, materials, costs, schedule, colour |
| `references/` | Style images and the site design references |
| `source/` | Python that regenerates the drawings and packs |
