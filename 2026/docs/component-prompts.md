# Crib 2026: every component, with an image prompt

Numbers match the blueprint (`crib-2026-blueprint.png`). Generate these as **reference images** for the build team. Use the same style lock for all of them so the pieces look like one world.

## How to use

1. Paste the **STYLE LOCK** at the start of every prompt (or set it as the system/first message in the other model).
2. Paste one component prompt after it. Generate 2–3 variations per item and keep the best.
3. Attach image 1 (daylight diorama) as a style reference for every item.
4. Work in this order: **A hero → B hill and cave → C fields → D village → E overhead → F backdrop → G tech**. Heroes first so every later piece matches them.

## STYLE LOCK (paste before every prompt)

```
Photorealistic photograph of a real handmade museum-quality diorama piece for a church Christmas crib, first-century Judean village style. Real materials: carved thermocol coated in plaster and sand, dry-brushed natural stone colours, real straw, clay, wool, linen and wood. Muted warm earth palette (sand, limestone cream, ochre, olive green, terracotta), slightly imperfect handmade finish, no plastic shine. Neutral light-grey studio background, soft even light, a 12-inch ruler visible for scale, sharp focus. No text, no logos, no modern objects.
```

Add this line to any item that shows a human figure: `Figures have natural proportions, hand-painted faces and cloth robes in muted colours, like fine Spanish or Italian nativity figures.`

## Tips for the other model

| Problem | Fix |
|---|---|
| Looks like a toy | add "fine art nativity figure quality, hand-painted, not plastic" |
| Colours too bright | add "muted, desaturated, earthy palette" |
| Text appears | add "no text, no letters" |
| Wrong scale | state the height in feet and add "a 12-inch ruler next to it" |
| Pieces don't match | attach image 1 and the first hero piece as reference for every new item |
