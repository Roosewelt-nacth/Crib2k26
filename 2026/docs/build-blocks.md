## Start order
- Start now, no dependencies: A, H (bench), J, and figures for B, C, E, G.

## Rules
- Every block has its own labelled base, carry handles and a power plug or lead.
- No block is wider than 4 ft, so each fits through the church door.
- Re-run the sightline check from V before fixing K or any tall item.
